Un petit projet AM Labs

Agent World.

Regardez vivre vos agents Hermes
dans un labo en pixel art.

Agent World est une interface visuelle open source pour suivre l’activité de vos agents Hermes, sur votre Mac ou sur un VPS. Des bureaux, un coin café, quelques bulles de pensée… et un canapé pour les pauses.

Télécharger sur GitHub ↗ (nouvel onglet) Code source ↗ (nouvel onglet)

Gratuit & open source · Mac Apple Silicon

Les états sont réels. Le café, un peu moins.

L’app lit les états d’Hermes et les met en scène, sans commander les agents. Les pauses et les pensées sont inventées pour le décor. Même quand quelqu’un dit « Bazinga ! ».

Un souci ? Signalez-le sur GitHub ↗ (nouvel onglet)Votre système, les étapes et le message d’erreur nous aideront. Sans données sensibles.

Pour l’essayer chez vous.

Un Mac Apple Silicon et Hermes déjà installé : suivez le guide d’installation. Configuration VPS disponible pour vos agents hébergés à distance. Aucun relais des données des agents par AM Labs.

L’app vérifie les mises à jour à l’ouverture, puis toutes les 24 h si elle reste ouverte. Un bouton apparaît lorsqu’une version est disponible ; vous choisissez de l’installer.

App Mac non notarisée · Licence MIT

Compatibilité du mode VPS

L’installation complète a été testée sur Debian 13 ARM64 avec OpenSSH et systemd. Le paquet serveur distribué est destiné à ARM64. Les autres systèmes et les serveurs Intel/AMD ne sont pas encore validés. Consultez le guide VPS et faites-nous part des problèmes rencontrés sur GitHub.
